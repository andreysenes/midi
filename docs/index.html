Casio SA-1 MIDI

GitHub

A placa M3210-MAIM(F) fica no teclado. O MCP23017 lê a matriz; o Raspberry Pi Pico manda USB-MIDI, lê dois EC11 e o joystick KY-023, e mostra estado no OLED. O PCM5102A fica no I2S para o synth no próprio Pico.
