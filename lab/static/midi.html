DAW

Grave o firmware MIDI no Pico. O Mac / a DAW vê dois portos: Casio SA-1 (teclado, pads CC, joystick) e Mackie Control (mixer). Na DAW: Control Surface = MackieControl, Input/Output = Mackie Control — não o Casio. Banco P1 = piano MIDI ch1, P2 = ch2, … P8 = ch8 (cada track no seu canal). Banco pads 1 = Mackie; bancos 2–8 = CC.
