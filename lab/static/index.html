SA-1

Clica no painel (T−, SEL, piano…) para aprender essa tecla. Aperta a física — ou clica com ela já premida — para gravar a posição KO/KI.

Tecla ou botão acende quando o hardware desce. No aprender, o amarelo a pulsar é a que deves carregar.

Matriz KO × KI

Amarelo = agora · vermelho = colado no boot · verde = histórico (opcional). Nome de cima = teórico Casio; de baixo = mapa aprendido se diferente.
